# nixos-iso

[![Build ISO](https://github.com/Guanran928/nixos-iso/actions/workflows/build.yaml/badge.svg)](https://github.com/Guanran928/nixos-iso/actions/workflows/build.yaml)

为中国用户定制的 NixOS ISO

提供 `minimal`、`gnome`、`plasma6` 三种镜像，通过 GitHub Actions 构建。

## 功能

- 默认使用 TUNA 的 nix-channels 镜像
- 默认启用 Fcitx 5 和 fcitx5-pinyin-addons
- 默认使用 Noto Sans CJK 而不是 GNU Unifont
- (`plasma6`, `gnome`) 默认启用 Clash Verge Rev, Throne 代理软件
